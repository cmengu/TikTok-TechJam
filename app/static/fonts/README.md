# Self-hosted webfonts

Two font families, self-hosted here so the app has no CDN dependency at demo
time. Both are licensed under the SIL Open Font License, Version 1.1.

## Instrument Sans

- Designer: Jack Halten Fahnestock
- License: SIL Open Font License 1.1
- Files:
  - `instrument-sans.woff2` — roman, variable weight 400–600
  - `instrument-sans-italic.woff2` — italic, weight 400
- Source (latin subset, fetched via the Google Fonts CSS2 API):
  - https://fonts.gstatic.com/s/instrumentsans/v4/pxiTypc9vsFDm051Uf6KVwgkfoSxQ0GsQv8ToedPibnr0SZe1ZuWi3g.woff2
  - https://fonts.gstatic.com/s/instrumentsans/v4/pxigypc9vsFDm051Uf6KVwgkfoSbSnNPooZAN0lInHGpCWNE27lgU-XJojENuu-2oy4H28zdQwQzNA.woff2
- Fetched from: `https://fonts.googleapis.com/css2?family=Instrument+Sans:ital,wght@0,400..600;1,400&display=swap`
